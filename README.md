# 随便记 Whatnote

<p align="center">
  <img src="Assets/Whatnote-icon.png" width="128" alt="随便记 app icon">
</p>

<p align="center">随手记下任何事的 macOS 桌面便签，仅支持 Apple Silicon。</p>

英文名 **Whatnote** 取自英语 “whatnot”（随便什么东西）加上 “note”（记），和中文名「随便记」对应。

本仓库 fork 自 [tonyjianchina/Deskbit](https://github.com/tonyjianchina/Deskbit)，在原版基础上改成个人专用版本：

- 液态玻璃（Liquid Glass）界面：按钮以玻璃胶囊的形式浮在便签上
- 蓝、绿、黄、粉四种浅色便签，黑色文字清晰易读，正文字号 18
- 可以点击勾选的圆形核对清单
- 支持 Markdown 语法、图片和链接
- 全局快捷键一键新建便签（默认 `⌃⌥⌘空格`，可在设置中修改）
- 开机自启动
- 只构建 Apple Silicon（arm64）版本，不再支持 Intel Mac
- 移除了用户反馈功能和多语言切换，界面固定为简体中文

便签内容只保存在本机，无需账号，也不会上传到服务器。

## 系统要求

- macOS 11 Big Sur 或更高版本
  - 液态玻璃效果需要 macOS 26 或更高版本，并用 Xcode 26 或更新的命令行工具构建；更早的系统显示为磨砂玻璃效果
  - 开机自启动需要 macOS 13 或更高版本
- Apple Silicon Mac（M 系列芯片）

## 从 Deskbit 升级

- 第一次打开随便记时，会自动把 `~/Library/Application Support/Deskbit/notes.json` 复制到 `~/Library/Application Support/Whatnote/notes.json`，原文件保留作为备份。
- 原来的便签保留各自的颜色类别，换成新的色调；原来 13、16 或 24 号的文字会自动换成 18 号。
- 应用标识换成了新的，所以自定义过的快捷键和开机自启动需要在设置里重新设置一次。
- 确认新版正常后，可以删除旧的 `/Applications/Deskbit.app`。

## 主要功能

- 蓝色、绿色、黄色和粉色四种便签配色
- 核对清单：圆形复选框，点击即可勾选或取消
- Markdown：标题、粗体、斜体、删除线、行内代码、链接、列表、核对清单、分隔线
- 图片：粘贴、拖入或通过底栏按钮插入，自动缩小以适应便签
- 链接：输入或粘贴的网址自动变成链接，也可以用 `⌘K` 添加或编辑，点击即可打开
- 全局快捷键，在任何应用中一键新建便签
- 登录时打开（在设置中开启）
- 多级项目符号，以 `•`、`∘`、`▪` 区分层级
- 在 Finder 桌面框选多张便签后整组移动、置顶或取消置顶
- 自动排列全部便签，或只排列当前框选的便签
- 未置顶时使用普通窗口层级；置顶后可跨桌面空间显示
- “已完成的便签”面板，可恢复或删除已完成的便签
- 自动保存富文本、图片、颜色、窗口位置和置顶状态

## 界面

每张便签由彩色纸面和浮在上面的玻璃按钮组成，文字滚动时会从玻璃按钮下方经过：

- 左上角：完成
- 右上角：四个颜色圆点（当前颜色显示得更大）、新建便签、置顶、排列便签
- 底部中间：粗体、项目符号列表、编号列表、核对清单、分隔线、插入图片

当前段落正在使用的格式（例如粗体）以及已置顶的状态，会在按钮后面显示一个便签同色系的底色。便签始终使用浅色外观，系统切换到深色模式时文字也清晰可读。

## 使用方法

### 全局快捷键

- 默认 `⌃⌥⌘空格`（Control + Option + Command + 空格）：在任何地方新建便签并直接开始输入。
- 修改：点击菜单栏随便记图标 → 设置…（`⌘,`），点按快捷键框后按下新的组合键。
  - 组合键必须包含 `⌘`、`⌥` 或 `⌃` 中的至少一个
  - `Esc` 取消录制，`Delete` 清除快捷键（即关闭全局快捷键）
  - “还原”回到 `⌃⌥⌘空格`
- 基于系统热键接口实现，不需要授予“辅助功能”权限。

### 开机自启动

- 菜单栏随便记图标 → 设置… → 勾选“登录时打开”。
- 建议先把 `Whatnote.app` 放进“应用程序”文件夹再开启：登录项记录的是 App 所在位置，放在构建目录里重新构建后可能失效。
- 如果系统要求确认，点“打开系统设置…”，在“通用 → 登录项”中允许随便记。

### 菜单栏

- 菜单栏只显示随便记图标，点击打开菜单。
- “显示所有便签”：把所有便签移到当前桌面并放到最前面，包括留在其他桌面（空间）或已断开显示器上的便签。

### 便签窗口

- 拖动顶部玻璃按钮之间的空白区域：移动便签。
- 拖动窗口边缘：调整便签大小。
- 点击颜色圆点：切换便签颜色。
- 点击 `+`：在当前便签附近、同一块显示器上新建便签。
- 点击图钉：置顶或取消置顶。
- 点击对勾：完成当前便签并移入历史。
- 点击右上角“排列便签”：在主屏幕自动排列，每列最多 4 张。

### 核对清单

- 行首输入 `- [ ] `、点击底部的“核对清单”按钮或按 `⇧⌘L`，把当前行变成核对清单项；再按一次变回普通文字。
- 点击圆圈或按 `⇧⌘U`（标记为已勾选）勾选或取消勾选。
- 点击前面的圆圈勾选完成：圆圈填充为便签的深色并显示对勾，文字加删除线；再点一次取消勾选。
- 在项目末尾按回车会自动新建下一项；在空的项目上按回车结束列表。
- 在圆圈后面按删除键，会把这一行变回普通文字（项目符号同理）。

### 已完成的便签

- 每条历史记录显示原颜色、内容摘要和完成时间。
- 空白便签（没有文字和图片）点对勾后直接删除，不进入历史。
- 点击“恢复”会将便签重新放回桌面，并以普通未置顶窗口打开。
- 单条永久删除和“清空历史”都会在操作前再次确认。
- 从 macOS 菜单栏打开“已完成的便签”；点击列表外任意位置即可收起。

## 数据与隐私

- 数据保存在 `~/Library/Application Support/Whatnote/notes.json`。
- 含图片的便签以 RTFD 格式保存；图片插入时会缩小到最长边 1600 像素，以控制文件大小。
- 快捷键设置保存在 `UserDefaults` 中。
- 随便记没有账号、云同步、广告、遥测或任何网络请求。

建议升级或更换电脑前备份上述 `notes.json` 文件。

## 从源码构建

在 Apple Silicon Mac 上安装 Xcode 命令行工具（Command Line Tools）后执行：

```bash
git clone https://github.com/yx1100/Deskbit.git
cd Deskbit
./scripts/build-app.sh
open "dist/Whatnote.app"
```

构建脚本生成仅包含 arm64 架构的 `dist/Whatnote.app`，在中文系统的访达、启动台和登录项中显示为“随便记”。

如需生成 DMG 安装包：

```bash
MARKETING_VERSION=1.3.0 BUILD_NUMBER=6 ./scripts/build-app.sh
./scripts/make-dmg.sh 1.3.0
```

### 运行检查

```bash
./scripts/build-app.sh
for test_script in scripts/test-*.sh; do "$test_script"; done
swift build
```

## 发布维护

发布工作流由 `vX.Y.Z` 标签或 GitHub Actions 手动触发。它会运行检查、构建 arm64 App、生成 ZIP 和 DMG、创建 GitHub Release，并更新 Homebrew Cask。
